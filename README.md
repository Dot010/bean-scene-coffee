
# ☕ Bean Scene — Coffee Landing Page

Uma landing page moderna, imersiva e de alta performance desenvolvida com **Next.js 15**, focada em proporcionar uma experiência visual elegante para uma marca de cafeteria artesanal.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas de desenvolvimento web:

* **[Next.js 15](https://next.js.org/)** (App Router) — Framework React focado em performance e otimização de rotas.
* **[React](https://react.dev/)** — Biblioteca para construção de interfaces de usuário.
* **[Tailwind CSS](https://tailwindcss.com/)** — Framework CSS utilitário para estilização rápida e responsiva.
* **[GSAP (GreenSock)](https://greensock.com/gsap/)** — Biblioteca robusta de animações para transições fluidas e efeitos visuais interativos.
* **TypeScript** — Superset JavaScript para maior segurança e escalabilidade do código.

---

## 🎨 Funcionalidades

* **Design Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e desktops.
* **Animações Dinâmicas:** Efeitos visuais imersivos e transições suaves alimentados por GSAP.
* **Componentes Modulares:** Estrutura organizada contendo Navbar, Hero Section, Canvas de Experiência e seções de destaque.
* **Performance Otimizada:** Aproveitamento dos recursos do Next.js 15 para carregamento rápido e SEO amigável.
